# Game Documentation for War Strike Mobile

## Game Features
- Thrilling combat mechanics
- Vivid graphics and immersive sound effects
- Intuitive controls for seamless gameplay

## Game Modes
- **Single Player**: Experience the story in immersive single-player mode.
- **Multiplayer**: Compete against players from around the world.
- **Co-op Missions**: Team up with friends to complete challenging missions.

## Character System
- Play as various unique characters each with distinct abilities and stats.
- Unlock new skills and upgrade character attributes through gameplay.

## Arsenal
- **Weapons**: A wide range of weaponry including guns, melee weapons, and explosives.
- **Gadgets**: Utilitarian items to enhance and diversify combat strategies.

## Monetization Model
- Free-to-play with microtransactions for cosmetic items and gameplay enhancements.
- Seasonal battle passes for exclusive content.

## Project Structure
- `src`: Main source code base.
- `assets`: includes all the graphic resources used.
- `docs`: Documentation and related resources.

## Tech Stack
- **Unity**: Game engine of choice for 3D rendering and Physics.
- **C#**: Scripting language for gameplay logic.
- **Photon**: Networking solution for multiplayer aspects.

## Development Status
- Currently in active development with a closed beta phase ongoing.

## Key Differentiators
- Unique character system that promotes varied play styles.
- Engaging storyline interwoven with multiplayer elements.

- Please fork the repository and submit a pull request for any contributions.
